# 🌤️ WeatherNow

A real-time weather application built with HTML, CSS, and JavaScript.

## 🚀 Project Overview
WeatherNow lets users search any city and instantly view current weather conditions including temperature, humidity, wind speed, visibility, and pressure.

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- Open-Meteo API (free, no key required)
- Open-Meteo Geocoding API

## 🤖 AI Tools Used
- Claude (Anthropic) — for code generation and project structure
